# Angel Lopez | Technology & Computer Portfolio

Minimalistic, plain, and modern personal portfolio website for **Angel Lopez** — TSA Member & Aspiring Computer Technician from Springfield, MO.

---

## 📋 Included Sections

1. **Header & Navigation**: Clean title bar with quick section links and a minimalist Light/Dark mode toggle.
2. **Welcome / Headline**: Angel Lopez • TSA Member & Aspiring Computer Technician | Springfield, MO.
3. **About Me**: Narrative background, school details (Pipkin Middle School, Class of 2030), and core focus areas.
4. **TSA Experience**: Drone Technology & Competition highlights, telemetry experience, and upcoming transition to Robotics.
5. **Hands-On Technical Experience**: Computer Hardware & Repair (local neighborhood tech helper) and Web Development foundations.
6. **Contact & Collaboration**: Direct contact details, one-click email copy button (`gabby11.al@gmail.com`), and an interactive message form.
7. **SEO Optimization**: Fully loaded with keywords, meta tags, and Schema.org JSON-LD structured data for search engine discovery.

---

## 🚀 How to Run Locally

### Option 1: Using Node.js
```bash
node server.js
```
Then visit **[http://localhost:3000](http://localhost:3000)**.

### Option 2: Direct File Open
Double-click [`index.html`](./index.html) in your file explorer to open it in any web browser.
